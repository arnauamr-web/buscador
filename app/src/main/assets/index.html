Primera vez: cómo prepararlo (5 minutos)
  1. Entra en supabase.com, crea una cuenta gratis y pulsa New project.
  2. Abre SQL Editor, pega el código de abajo y pulsa Run.
  3. Abre Authentication → Users → Add user → Create new user. Pon un correo y una contraseña y marca Auto Confirm User.
  4. Abre Project Settings → API. Copia la dirección (Project URL) y la clave anon o publishable, y pégalas arriba.
