# Mi Nube

App para guardar fotos, vídeos y documentos en carpetas y verlos desde el móvil y desde el ordenador, sin descargarlos.

- Carpetas que puedes crear, colorear, ordenar y meter unas dentro de otras.
- Etiquetas, favoritos y papelera de 30 días.
- Carpetas secretas: se abren escribiendo un código en el buscador.
- Enlaces para compartir un archivo con caducidad.

## Instalar

1. Cada vez que se sube un cambio, GitHub compila la app solo (pestaña **Actions**, unos 2 minutos).
2. Abre **Releases**, entra en **Mi Nube (última versión)** y toca `Mi-Nube.apk` para instalarla en el móvil.
3. En el ordenador, descarga `Mi-Nube-ordenador.html` y ábrelo con el navegador.

## Preparar Supabase (solo la primera vez)

Dentro de la app, en la pantalla de entrada, hay un apartado «Primera vez» con los pasos y el código SQL para copiar.
